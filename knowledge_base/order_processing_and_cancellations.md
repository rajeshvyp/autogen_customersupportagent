# Order Processing, Changes and Cancellations
Version: 1.0 | Owner: Order Operations

## Order processing
Orders are normally prepared within 1 business day. Payment verification, stock checks, weekends and public holidays can delay processing.

## Cancellation request
A customer may request cancellation while an order is still in a cancellable state. The support agent must check the order status. If already dispatched, explain that cancellation may no longer be possible and provide the returns process.

## Change of item or quantity
Changes are not guaranteed after payment confirmation. If the order has entered picking or packing, the customer may need to wait for delivery and use the applicable return process.

## Pre-orders and backorders
The estimated release or availability date is shown on the product or order page. Estimates can change. Do not create a new date if the source record does not contain one.

## Out-of-stock item
If an item becomes unavailable after purchase, refer the case to Order Operations. Do not promise a substitute without customer agreement.

## Duplicate orders
Confirm both order IDs and whether both have shipped. Route suspected accidental duplicate purchases to Order Operations; route duplicate payment captures to Finance.

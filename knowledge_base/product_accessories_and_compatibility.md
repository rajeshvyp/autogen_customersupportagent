# Accessories and Compatibility Guide
Version: 1.0 | Owner: Product Team

## Chargers
Use a charger that meets the device manufacturer's required voltage, current and charging protocol. Check the exact model documentation. Do not recommend an unknown third-party charger for a device with a reported overheating issue.

## USB-C docks
USB-C connectors do not guarantee that every port supports video output, charging or the same data speed. Confirm the laptop SKU and dock specification.

## Cases and screen protectors
Confirm exact model dimensions and camera/button layout. Similar product names may have different physical dimensions.

## Memory and storage
Some products support external storage while others do not. Check the exact product specification before advising.

## Monitor arms
Check VESA mounting pattern, monitor weight and stand removal instructions in the product manual.

## Accessory fault
If an accessory is defective, collect its model, order ID and fault description. Apply the same return and warranty assessment process where eligible.

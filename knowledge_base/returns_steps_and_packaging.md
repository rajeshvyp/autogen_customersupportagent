# Return Steps and Packaging Guide
Version: 1.0 | Owner: Returns & Refunds

## Standard return steps
1. Locate the order confirmation and order ID.
2. Submit a return request through the customer account or support channel.
3. State which item is being returned and why.
4. Wait for return instructions and any required authorisation.
5. Pack the item securely with included accessories.
6. Use the provided label or the approved carrier instructions.
7. Keep the drop-off receipt and tracking reference.
8. Monitor the return until received and assessed.

## Packaging
Use protective packaging suitable for the item. For fragile electronics, protect screens and corners. Do not attach labels directly to the retail product box unless instructed.

## Multiple-item orders
List each item being returned. Items from separate shipments may require separate return labels.

## Missing accessories
Tell support which accessories are missing. The assessment team decides whether the return can proceed and whether any adjustment applies.

## Return tracking
A return is not confirmed as received until the returns facility records it. A carrier scan alone may not mean the inspection is complete.

## Unsafe or swollen batteries
Do not place damaged, swollen or overheating batteries in ordinary return packaging. Stop using the item and escalate to Technical Service for safe handling instructions.

# Troubleshooting Guide — Routers and Wi-Fi
Version: 1.0 | Owner: Technical Service

## No internet connection
1. Check whether the modem/router status lights indicate a connection.
2. Confirm whether all devices or only one device are affected.
3. Restart network equipment using the manufacturer's normal procedure.
4. Check for a known service outage with the internet provider.
5. If the router itself appears faulty, collect model and status-light details.

## Weak Wi-Fi signal
Move the router to an open central location, away from large obstructions and interference sources. Mesh nodes should be placed where they still receive a stable signal from the main router.

## Mesh node will not pair
Confirm model compatibility, firmware version and setup sequence. Reset only according to the product manual.

## Guest network
Explain that a guest network separates visitor access from the main network when supported. Do not promise identical features across all router models.

## Security
Recommend a unique Wi-Fi password and current supported firmware. Escalate suspected router compromise.
